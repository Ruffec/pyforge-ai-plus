自动检测流程

应用启动时按以下顺序检测平台环境，并据此加载对应平台配置。

1 检测操作系统
OS 检测 platform.system() 识别当前操作系统类型
2 检测系统架构
CPU 架构识别 x64 / arm64 / armv7l 匹配对应架构二进制
3 检测包管理器
按平台匹配 winget / brew / apt Windows: winget; macOS: brew; Linux: apt/yum/pacman
4 检测 Shell 环境
默认 Shell 识别 PowerShell / zsh / bash 确定脚本类型与配置文件
5 加载平台配置
自动切换 paths / scripts / separators 切换路径、脚本类型、分隔符
